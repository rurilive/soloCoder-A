# 函数可视化工具 - 产品需求文档

## Overview
- **Summary**: 构建一个基于Web的函数可视化工具，用户可以输入数学表达式（二元或三元函数），生成2D或3D图形，并支持多个函数图形之间的集合运算（并集、交集、差集、对称差）。
- **Purpose**: 为数学学习者、工程师和研究人员提供直观的函数可视化工具，帮助理解函数的几何形状和不同函数之间的关系。
- **Target Users**: 学生、教师、工程师、数据科学家、数学爱好者

## Goals
- 支持二元函数（2个变量）生成2D曲线图或3D曲面图
- 支持三元函数（3个变量）生成3D等值面图
- 支持同时输入多个函数表达式
- 支持多个函数图形之间的集合运算（并集、交集、差集、对称差）
- 提供交互式Web界面，支持旋转、缩放、平移3D图形
- 支持自定义可视化参数（颜色、透明度、采样精度等）

## Non-Goals (Out of Scope)
- 不支持符号计算（求导、积分等）
- 不支持动画或时间维度的可视化
- 不提供离线桌面版本
- 不支持实时协作编辑
- 不支持复杂的脚本编程

## Background & Context
- **技术架构**: 采用前后端分离的设计模式
  - 后端: FastAPI + Python（负责数学表达式解析、函数计算、集合运算）
  - 前端: Jinja2模板 + JavaScript + Three.js（负责3D渲染和用户交互）
- **依赖库**:
  - Python: numpy（数值计算）、sympy（符号计算辅助）、uvicorn（ASGI服务器）
  - 前端: Three.js（3D渲染）、Plotly.js或Chart.js（备选2D渲染）

## Functional Requirements
- **FR-1**: 用户可以输入一个或多个数学表达式
  - 支持二元函数格式: `f(x, y) = x^2 + y^2` 或简写 `x^2 + y^2`
  - 支持三元函数格式: `f(x, y, z) = x^2 + y^2 - z^2` 或简写 `x^2 + y^2 - z^2`
  - 每个函数可以单独命名

- **FR-2**: 支持多种数学函数和运算符
  - 基本运算符: `+`, `-`, `*`, `/`, `^`（幂）
  - 三角函数: `sin`, `cos`, `tan`, `asin`, `acos`, `atan`
  - 指数/对数: `exp`, `log`, `log10`, `sqrt`
  - 绝对值/符号: `abs`, `sign`
  - 常量: `pi`, `e`

- **FR-3**: 二元函数可视化
  - 2D模式: 显示等高线图或z=f(x,y)的2D投影
  - 3D模式: 显示曲面图

- **FR-4**: 三元函数可视化
  - 生成等值面图（isosurface）
  - 用户可指定等值面值

- **FR-5**: 多个函数的集合运算
  - **并集 (Union)**: 显示所有函数图形的合并区域
  - **交集 (Intersection)**: 仅显示所有函数共有的区域
  - **差集 (Difference)**: 从第一个函数中减去其他函数的区域
  - **对称差 (Symmetric Difference)**: 显示所有不重叠的区域

- **FR-6**: 可视化参数配置
  - 坐标轴范围设置
  - 采样精度/分辨率设置
  - 颜色方案选择
  - 透明度设置
  - 是否显示网格、坐标轴标签

- **FR-7**: 交互式操作
  - 3D图形旋转（鼠标拖动）
  - 缩放（滚轮）
  - 平移（右键拖动或中键）
  - 重置视图

## Non-Functional Requirements
- **NFR-1**: 性能要求
  - 2D图形渲染: < 1秒
  - 3D曲面图渲染: < 3秒（中等精度）
  - 页面加载时间: < 5秒
  - 支持的最大顶点数: 50万（保持流畅交互）

- **NFR-2**: 安全性
  - 数学表达式解析必须安全，防止代码注入
  - 不执行任意用户代码
  - 表达式解析在沙箱环境中进行

- **NFR-3**: 可用性
  - 界面简洁直观，无学习成本
  - 提供预设示例函数
  - 错误提示友好清晰

- **NFR-4**: 兼容性
  - 支持主流现代浏览器（Chrome, Firefox, Safari, Edge）
  - 响应式设计，支持桌面端

## Constraints
- **Technical**: 
  - 后端语言: Python 3.9+
  - Web框架: FastAPI
  - 模板引擎: Jinja2
  - 3D渲染库: Three.js
  - 包管理: uv
- **Business**: 
  - 单用户部署，无多用户认证需求
  - 无持久化存储需求（可选导出图片功能）
- **Dependencies**: 
  - numpy >= 1.20
  - sympy（可选，用于表达式验证）
  - Three.js（CDN引入）

## Assumptions
- 用户具有基本的数学知识，理解二元/三元函数概念
- 用户的浏览器支持WebGL
- 所有计算在服务器端完成，前端仅负责渲染
- 表达式使用标准的数学符号

## Acceptance Criteria

### AC-1: 单个二元函数可视化
- **Given**: 用户打开Web应用
- **When**: 用户输入二元函数表达式（如 `x^2 + y^2`）并点击"生成"
- **Then**: 系统应显示该函数的3D曲面图，支持鼠标旋转查看
- **Verification**: `programmatic`
- **Notes**: 验证生成的网格数据正确，渲染可见

### AC-2: 数学表达式解析
- **Given**: 用户输入函数表达式
- **When**: 表达式包含各种数学函数（sin, cos, exp, log, sqrt等）
- **Then**: 系统应正确解析并计算，无报错
- **Verification**: `programmatic`
- **Notes**: 测试多种复杂表达式

### AC-3: 无效表达式处理
- **Given**: 用户输入无效的表达式
- **When**: 表达式包含语法错误或不支持的函数
- **Then**: 系统应显示友好的错误提示，不崩溃
- **Verification**: `programmatic`
- **Notes**: 确保安全，无代码注入风险

### AC-4: 多个函数输入
- **Given**: 用户界面
- **When**: 用户添加多个函数表达式（至少2个）
- **Then**: 系统应允许添加/删除函数输入框，每个函数可独立命名
- **Verification**: `human-judgment`
- **Notes**: UI测试，确认多个输入框可用

### AC-5: 并集运算
- **Given**: 用户已输入2个二元函数
- **When**: 用户选择"并集"运算并生成
- **Then**: 显示两个曲面的合并区域，两个曲面都可见但不相互遮挡
- **Verification**: `programmatic`
- **Notes**: 验证数据合并逻辑正确

### AC-6: 交集运算
- **Given**: 用户已输入2个重叠的二元函数
- **When**: 用户选择"交集"运算并生成
- **Then**: 仅显示两个函数共有的重叠区域
- **Verification**: `programmatic`
- **Notes**: 验证阈值检测逻辑正确

### AC-7: 差集运算
- **Given**: 用户已输入函数A和函数B
- **When**: 用户选择"差集"（A - B）并生成
- **Then**: 显示函数A中不与函数B重叠的部分
- **Verification**: `programmatic`
- **Notes**: 验证减法逻辑正确

### AC-8: 对称差运算
- **Given**: 用户已输入函数A和函数B
- **When**: 用户选择"对称差"运算并生成
- **Then**: 显示所有不重叠的区域（A不与B重叠的部分 + B不与A重叠的部分）
- **Verification**: `programmatic`
- **Notes**: 验证异或逻辑正确

### AC-9: 三元函数等值面
- **Given**: 用户输入三元函数表达式（如 `x^2 + y^2 + z^2`）
- **When**: 用户指定等值面值（如 25）并生成
- **Then**: 显示对应的3D等值面（如半径为5的球体）
- **Verification**: `programmatic`
- **Notes**: 验证等值面算法正确

### AC-10: 参数配置
- **Given**: 用户已输入函数
- **When**: 用户修改坐标轴范围、采样精度、颜色、透明度等参数
- **Then**: 图形按新参数重新渲染，效果符合预期
- **Verification**: `human-judgment`
- **Notes**: UI交互测试

### AC-11: 交互操作
- **Given**: 3D图形已显示
- **When**: 用户用鼠标拖动（旋转）、滚轮（缩放）、右键拖动（平移）
- **Then**: 图形应响应这些操作，交互流畅
- **Verification**: `human-judgment`
- **Notes**: 浏览器交互测试

### AC-12: 预设示例
- **Given**: 用户首次打开应用
- **When**: 页面加载完成
- **Then**: 显示几个预设的示例函数，用户可快速选择生成
- **Verification**: `human-judgment`
- **Notes**: 验证预设功能存在且可用
